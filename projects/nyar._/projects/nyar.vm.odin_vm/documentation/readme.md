# OdinVM

OdinVM 是 OVM 目标 `.odin` 产物的执行环境，拥有模块加载和验证、执行帧、VM 对象、GC 及可选 JIT。语言语义由各语言前端、解释器和目标适配器负责，不由 VM 按语言名称推测。

OVM 目标私有计划经 LIR 验证和编码形成 `.odin`。加载器验证格式、版本、索引、跳转、调用签名及资源需求，再执行真实入口。解释器和 JIT 必须维持相同执行合同，不支持能力必须明确拒绝。

Wasm、CLR、JVM 和 native 直接生成各自产物，不经 `.odin`。LegendVM 提供 guest 解释与专门化支撑，与 OdinVM 的产物执行职责分离。本文是职责合同，具体支持范围须按实际实现核验。
