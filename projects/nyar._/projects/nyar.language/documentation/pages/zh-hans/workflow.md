# 工作流

先由语言前端产生本语言的完整语义事实，再选择静态降低或解释器专门化路线。两条路线都保留语言语义所有权，不强制归一到 Valkyrie MIR。

按 [语言接入合同](frontend-contract.md) 使用 Nyar 的变换、分析、优化及 PE 工具。语言与目标适配器产生目标私有计划和 LIR，目标验证后编码并装配产物。OVM 使用 `.odin`，其余目标直接生成各自产物。

逐阶段验证事实来源和合法性。能力不足应明确拒绝或保留经声明的 residual/runtime 依赖，不允许按函数名或类型形状猜测。目录边界见 [源码布局](source-layout.md)。
