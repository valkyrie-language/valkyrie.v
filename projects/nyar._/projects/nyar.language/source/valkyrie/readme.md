# Valkyrie 前端

本包拥有 Valkyrie 的语义分析、诊断、HIR/MIR 和语言验证。语法树及恢复解析由 Oak 侧语法能力提供，前端消费语法事实。Valkyrie MIR 不作为其他语言必须实现的 Nyar 公共 IR。

Nyar 提供可复用变换、分析、优化和专门化工具。语言与目标适配器将已验证的 Valkyrie IR 或 residual 降低到各目标私有计划与 LIR；运行时、编码与打包不由前端直接发射。

V 侧尚未实现完整源码 Compiler。正式构建必须明确报告能力缺口，不能用函数体重解析、宿主代编译、空产物或独立 emitter 入口伪装成功。职责合同不等于当前实现支持。
