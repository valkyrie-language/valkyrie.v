# database._ 数据库生态 workspace

`database._` 是数据库产品线的顶层 workspace，承载共享存储内核与两条物理分离的产品线。

## 产品线

- `database`：所有实现共用的引擎抽象层（合同与内存参考引擎）
- `yyds.kv`：`yyds` 的 KV 存储内核，定义分片级 KV 合同
- `yydb`：单机数据库，嵌入式、本地优先，适合 sidecar 与缓存场景，带 KV 高速缓存能力
- `yyds`：分布式数据库，面向多节点与协议接入

## 边界约束

- `yydb` 可作为 `yyds` 的 sidecar 高速缓存，但不是 `yyds` 的一部分
- 二者可升降级、迁移、复制与数据搬运，但必须物理拆包，避免退化成单体数据库
- `database` 抽象层只拥有引擎合同：键编码、记录、读写路径、游标、批量、事务、日志语义、失败模型与观测；查询、协议与网络不进抽象层
- `yyds.kv` 只拥有分片级合同：键、值、记录、扫描、提交边界；不拥有查询、schema、协议
