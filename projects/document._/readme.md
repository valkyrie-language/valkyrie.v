# document._

`document._` 是文档处理与渲染框架 `notedown` 的顶层 workspace。

## 定位

- 文档语义 IR：文档图、关系、资产与校验
- 格式导入导出：Markdown / DOC / DOCX / EPUB / PDF / HTML
- 文档语义 IR 与其线格式合同由本仓设计与维护

## 下游

- `panduck`：文档转换编排
- `pandark` / `vutex`：渲染与消费侧产品
